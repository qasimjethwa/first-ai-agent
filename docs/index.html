      You just built one. Here's what you learned.
      
          
      How real AI agents work
      
          
      An agent is a loop, not magic: perceive → plan → act with tools → remember. Yours runs that loop on every message — in your browser, with zero code and no API key.
      
        
      
        
      
          
      01
      Perceive
      
            
      Your agent reads your message and figures out what you want: a calculation, a quiz, a question about your notes. Real agents do this with a language model — yours does it with intent matching, and you can watch it happen in the brain panel.
      
            
      You did this every time you sent a message in Chat.
      
          
      02
      Plan
      
            
      Before answering, the agent breaks the job into steps: find the facts → pick the tool → run it → compose the answer. Planning is what separates an agent from a chatbot — it decides how to solve the problem, not just what to say.
      
            
      You did this when you watched the step list animate in the brain panel.
      
          
      03
      Act with tools
      
            
      Tools are how agents touch the world — calculators, search, code runners. Your agent has 10 real ones and chooses between them per message. Toggling tools in the Studio is exactly how production agents get their capabilities scoped.
      
            
      You did this in the Studio's tool grid — every toggle reshaped what your agent can do.
      
          
      04
      Remember
      
            
      Agents keep two memories: the conversation (short-term) and facts worth keeping (long-term). Yours stores both — chat history plus anything you tell it to remember — persisted in your browser.
      
            
      You did this the first time you said “remember that…”.
      
        
      
        
      
          
      The loop, one more time
      
          
      
            Your message→
            Understand→
            Plan→
            Use a tool→
            Answer→
            Remember
          
      
          
      Swap the rule-based brain for an LLM API and add web tools, and this is the architecture running inside production AI agents.
